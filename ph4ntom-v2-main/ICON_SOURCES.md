# Token icon assets

Bundled for consistent offline rendering.

The app icon uses `Phantom-Icon_App_1200x1200.png` and `Phantom-Icon_Square_1200x1200.png` from the user-supplied `Phantom-Integration-Assets.zip`. Copies of those source images are in `assets/brand/`.

- WIF: https://s2.coinmarketcap.com/static/img/coins/128x128/28752.png
- HYPE: https://s2.coinmarketcap.com/static/img/coins/128x128/32196.png
- JUP: https://s2.coinmarketcap.com/static/img/coins/128x128/29210.png
- BONK: https://s2.coinmarketcap.com/static/img/coins/128x128/23095.png
- PENGU: https://s2.coinmarketcap.com/static/img/coins/128x128/34466.png

Bitcoin and USDC use the existing bundled vectors. Ethereum uses the existing diamond vector with the gray colors from the supplied reference. Solana uses the existing bundled gradient vector. Cash uses a locally authored banknote SVG.
